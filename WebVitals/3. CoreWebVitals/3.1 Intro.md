# Core Web Vitals

Core Web Vitals help measure the performance of a website.

They focus on three aspects of measuring the user experience:

1. **The load time**, measured using **LCP**
2. **The interaction time**, measured using **INP**
3. **The visual stability**, measured using **CLS**

All of these are measured for at least **75% of the users**, or the **75th percentile of page loads**.
